# Freight Rate Prediction Challenge

Machine learning assessment for predicting freight `posted_rate` values from historical load data.

The solution uses chronological validation to simulate future-period forecasting and compares a linear Ridge baseline with CatBoost regression models.

## Project Overview

The labeled development dataset contains 48,000 freight loads covering January through October 2025.

The final prediction dataset contains 12,000 unseen loads covering November and December 2025.

The target variable is:

`posted_rate`

## Approach

The solution includes:

- Data-quality checks and preprocessing for missing and invalid values
- Temporal and route-based feature engineering
- Chronological train/validation splits instead of random splitting
- Ridge regression as a baseline
- CatBoost regression using native categorical features
- A secondary two-month backtest to better represent the final prediction horizon

The final 12,000 predictions use the richer CatBoost feature set.

A separate common-feature CatBoost model is used for the fixed December prediction task because the supplied December input contains a smaller feature set.

## Repository Contents

- `spotter_solution.ipynb` — streamlined end-to-end solution used to generate the required predictions
- `spotter_assessment_full.ipynb` — detailed exploratory analysis, validation experiments, and model development
- `validation_predictions.csv` — final predictions for the 12,000 validation loads
- `december_chart_inputs_completed.csv` — completed fixed December predictions
- `candidate_december.png` — December chart generated by the provided scorer
- `ML_assessment_report.pdf` — assessment report and validation summary
- `requirements.txt` — Python dependencies

The original assessment datasets and provided scoring script are not included in the repository.

## Installation

Install the required dependencies:

```bash
python -m pip install -r requirements.txt

```

## Running the Solution

Place the following provided assessment files in the repository root:

- `train-test.csv`
- `validation.csv`
- `validation-predictions-template.csv`
- `december-chart-inputs.csv`

Then open:

`spotter_solution.ipynb`

and run all cells from top to bottom.

The notebook generates:

- `validation_predictions.csv`
- `december_chart_inputs_completed.csv`

## Validation

The provided scoring script can be run with:

```bash
python score.py --predictions validation_predictions.csv --december-predictions december_chart_inputs_completed.csv
```

The final submission was successfully validated by the provided scorer for:

- 12,000 final predictions
- 31 fixed December predictions

Final hidden validation metrics are calculated by Spotter after submission.
